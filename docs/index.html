Why RustCord

Small footprint. Full Discord.

Everything you need from a modded Discord client, without shipping an entire browser with it.

Rust + Tauri core

A native Rust backend with Microsoft WebView2 instead of a bundled Chromium runtime. Fast startup, small installer.

Low RAM usage

Around 60–100 MB in normal use, depending on Discord and the plugins you load. Much lighter than Electron clients.

Vencord by default

Vencord is enabled automatically on first launch, so themes, plugins, and quality-of-life tweaks are ready to go.

Shelter included

Shelter ships with RustCord for plugin loading and extra customization, alongside the Vencord ecosystem.

Multiple profiles

Keep separate sessions, settings, and accounts without reinstalling or clearing your config every time.

Desktop integration

Tray icon, native notifications, global keybinds, streamer mode, push-to-talk, and discord:// link support.
